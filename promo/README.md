# Shared Memory 학교 게시용 홍보물 (2026-10-24)

앱(사이트) 코드와 분리된 홍보물 세트입니다. 두 장을 나란히 붙이도록 같은 디자인 시스템(`promo.css`)을 씁니다.

| 파일 | 내용 |
|---|---|
| `dist/shared-memory-poster-A4.pdf` | ① QR 참여 포스터 (A4 세로, 인쇄용) |
| `dist/shared-memory-notice-A4.pdf` | ② 프로젝트 소개·참여 안내문 (A4 세로, 인쇄용) |
| `poster.html` · `notice.html` | 수정 가능한 원본 (브라우저로 열면 A4 크기 그대로 보임) |
| `promo.css` | 공통 디자인 (색·서체·머리줄·QR 띠) |
| `assets/qr-shared-memory.svg` | QR (벡터) — `https://oseungye.github.io/shared-memory-Korea/` |
| `assets/memory-card-sample.png` | 실제 앱 기본 체험(임진왜란)에서 앱의 ‘이미지로 저장’으로 만든 카드 예시 (가짜 DB로 실행, 운영 DB 기록 없음) |
| `build-promo.js` | QR 다시 만들기 + PDF 2장 출력 + 배치 점검 |

## 인쇄

- PDF를 그대로 인쇄: **A4 · 실제 크기(100%)**. 프린터가 가장자리를 비우므로 바깥 아이보리 테두리 일부가 흰색으로 남을 수 있으며, 내용은 안쪽 테두리(7mm) 안에 있습니다.
- HTML에서 인쇄할 때: 인쇄 창에서 **여백 없음**, **배경 그래픽 켜기**.
- A3로 크게: PDF를 인쇄소에서 A3로 확대하면 됩니다. 글자는 PDF에 벡터로 들어 있고 QR도 벡터라 깨지지 않습니다(카드 예시 사진만 비트맵).
- 붙이는 곳·효과 확인 방법은 [`../docs/participation-campaign.md`](../docs/participation-campaign.md).

## 고치기

- 문구: `poster.html` · `notice.html`의 본문을 직접 고칩니다. 앱의 실제 동작과 맞는 문구만 써 주세요(아래 ‘문구 근거’).
- 안내문의 **‘의견 전하는 곳’**과 **서명**은 브라우저에서 눌러 바로 고칠 수 있습니다(점선 칸, 저장되지 않음). 비워 두고 인쇄해 손으로 써도 됩니다.
- 다시 만들기: `node promo/build-promo.js` (Playwright·인터넷 필요 — 서체를 Google Fonts에서 받음). 내용이 A4를 넘치거나 서체·그림을 못 불러오면 PDF를 만들지 않고 실패로 끝납니다.

## 문구 근거 (앱 실제 동작, 2026-10-24 main 기준)

| 홍보물 문구 | 앱 |
|---|---|
| 역사 서술 비교 → 관점 선택 → Memory Card | 기본 체험(임진왜란·재일조선인): 세 나라 기록 비교 → 관점 고르기 3문항(정답 없음, 건너뛰기 가능) → 한 줄 소감(선택) → My Memory Card |
| AI의 답변 비교 | ‘AI는 어떻게 말할까?’(네 번째 서술자)는 **심화 탐구**에 있음 → 포스터에 “AI의 답변·단어 분석·사료는 ‘심화 탐구’에서”라고 구분 |
| 3–5분 · 익명 · 로그인 불필요 · 정답 없음 | 첫 화면 문구와 같음. 3–5분은 목표 시간(실측 아님) |
| 이름·연락처·학교를 묻지 않음 | 기본 체험은 이름·연락처·학교·연령대를 묻지 않음 (FAQ ‘학생 데이터는 어떻게 보호하나요?’) |
| 고른 관점·한 줄 소감은 이름 없이 저장, 다른 참여자에게 비공개 | `exploration_choices` · `exploration_reflections` (anon은 등록만, 조회 불가) |
| 참여자 수를 세기 위해 사건 이름과 브라우저의 무작위 번호만 기록 | `participation_pings` (사건 이름 + 무작위 참여자 키) |
| Memory Card 이미지는 휴대폰 안에서만 만들어짐 | 카드는 브라우저 Canvas로 그리고 서버로 보내지 않음 |
| 공개 아카이브에는 직접 동의한 문장만 | 공동 표현 공개 등록은 별도 동의 체크 후에만 |
| 1592년 같은 전쟁의 세 이름 | `events-data.js` 임진왜란 `title` · `titleJP` · `titleCN` (일본어 가운뎃점은 일본어 표기 `・`로 씀) |
| 2026 대한민국 고등학생 AI·SW 개발 공모전 본선 진출작 | 운영자 제공 문구 |

## 점검 결과 (2026-10-24)

- 두 PDF 모두 A4(595 × 842pt) **1쪽**, 내용이 안쪽 여백을 넘지 않음(`build-promo.js` 검사).
- 서체: Noto Serif KR · Noto Sans KR · Cinzel · Noto Serif JP · Noto Serif SC가 PDF에 **내장**됨. 한글·일본어·중국어 대체 글꼴(WenQuanYi 등) 사용 0건(주소 표기용 고정폭 글꼴만 시스템 대체).
- QR: 버전 5(37×37칸), 오류 복원 Q, 포스터 약 54mm 상자 · 안내문 약 30mm 상자(여백 포함).
  PDF를 이미지로 바꿔 QR 판독기(jsQR)로 확인 — 300dpi, A4 전체를 1200px·900px로 줄여 흐리게 한 사진, QR을 비스듬히·어둡게·흐리게 찍은 사진, 15° 회전·대비 낮춤 **10가지 모두** 배포 주소로 정확히 읽힘.
- **사람이 확인할 것**: 실제 인쇄물을 iPhone·Android 기본 카메라, 카카오톡·네이버 앱으로 1–2m에서 찍어 보기(위 검사는 휴대폰을 흉내 낸 것), 학교 프린터의 색(적갈색·먹색 띠) 확인.
