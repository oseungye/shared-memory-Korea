# AI 활용 범위와 개발자 기여

이 문서의 **1·2절은 저장소 기록으로 확인한 사실**이고, **3절은 개발자가 직접 채우는 칸**입니다.
3절을 다른 사람이나 AI가 대신 쓰지 마세요. 심사에서 가장 많이 확인하는 부분이며, 발표·질의응답에서 같은 내용을 말로 설명할 수 있어야 합니다.

## 1. 서비스 안에서 AI를 쓰는 곳 (2곳)

| 기능 | 무엇을 하나 | 쓰지 않는 것 |
|---|---|---|
| 네 번째 서술자 | 같은 질문(사건 이름 없이 연도·사실로만)을 한국어·일본어·중국어로 Claude(`claude-opus-5-5`)에 각 3회 물은 답 54건을 2026-10-22에 기록(`tools/collect-ai-narratives.mjs` → `ai-narratives-data.js`). 화면은 기록만 보여 주며 모델·수집 시각을 함께 표시. ‘기억의 빈자리’는 이 기록과 세 나라 요약을 규칙(개념 사전)으로 비교 | 실시간 호출 없음. 기록을 손으로 고치지 않음 |
| 질문하는 AI (심화 탐구) | 학생이 외부 전송에 동의하고 ‘시작’을 누른 경우만, Edge Function(`supabase/functions/ask-ai/`)이 Anthropic API에 학생 답과 사이트 자료를 보내 짧은 반응·근거·다음 질문을 받음(최대 2회, 하루 250회·IP당 시간당 200회 한도). 근거 id가 사이트 자료에 없으면 보여 주지 않음 | 학생 답·AI 응답 저장 없음. 판정·점수 없음. 실패하면 미리 써 둔 질문으로 진행 |

**AI를 쓰지 않는 곳**: 세 나라 서술 비교(TF-IDF·코사인·Jaccard), 참여 문장 분석(군집화·프레이밍), 기억의 빈자리 계산, 참여자 수 집계, 개인정보 검사 — 모두 규칙 기반이며 코드로 결과의 근거를 보여 줍니다.

## 2. 개발 과정의 AI 도구 사용 (저장소 기록)

- 개발에 AI 코딩 도구 **Claude Code**를 사용했습니다. 2026-11-07 `main` 75cb522 기준 병합 커밋을 뺀 커밋 79개 중 68개에 `Co-Authored-By: Claude` 표시가 있고, 커밋 작성자 이름은 `Claude` 62개 · `oseungye` 15개 · `OhSeungWan` 2개입니다(`git log`로 누구나 확인 가능, 단계별 정리는 [DEVELOPMENT_EVIDENCE.md](DEVELOPMENT_EVIDENCE.md)).
- 저장소의 `.claude/settings.json`은 AI 도구가 운영 DB를 바꾸는 명령(`execute_sql`·`apply_migration` 등)을 실행하기 전에 사람의 확인을 받도록 설정되어 있습니다.
- 세 나라 요약 서술·사료 선정·편집자 관찰·객관식 선택지 같은 **역사 콘텐츠**와, 운영 결정(예: 기본 체험 답을 동의 없이 이름 없이 저장, 질문하는 AI 켜기)이 누구의 판단인지는 아래 3절에 개발자가 직접 적습니다.

## 3. 개발자 기여 — 직접 작성 (질문에 답하는 형식)

각 질문에 2–5문장으로, **구체적인 장면·이유·숫자**를 넣어 답해 주세요. 모르는 것은 “AI가 제안했고 나는 ○○를 확인했다”처럼 솔직하게 쓰는 편이 심사에서 유리합니다.

> **읽는 법** — 각 질문 아래 `기록 참고`는 저장소 기록(커밋·PR)에서 찾은 **사실 재료**이며 AI가 정리했습니다. 답이 아닙니다. `> 답:` 칸은 개발자가 직접 씁니다. 기록이 실제와 다르면 고쳐 주세요. **[본인 확인 필요]** 표시는 기록만으로 알 수 없는 부분입니다.
