# 사료 검증 기록 (2026-11-08)

`sources-data.js`에 등록된 사료 21건을 최종 제출 전에 다시 점검한 기록입니다. 각 사료의 `verification`·`verificationNote`·`checkedAt`에 같은 내용이 들어 있습니다.

## 검증 방법

1. **원문 우선**: 국가기관·공공 아카이브·학술기관이 제공하는 원문 페이지를 먼저 찾았습니다.
   (국사편찬위원회 조선왕조실록·한국사데이터베이스, 일본 국립국회도서관 디지털컬렉션, 일본 중의원, 나고야대학 법령 DB, UNESCO, 히로시마 평화기념자료관, 트루먼 대통령 도서관)
2. **페이지를 직접 열어 대조**: 링크가 열리는지만 보지 않고, 페이지 안의 자료명·작성 주체·연도와 우리 설명이 맞는지 본문으로 확인했습니다.
3. **원문을 찾지 못하면 학술 사전으로 서지만 확인**: 『한국민족문화대백과사전』(한국학중앙연구원), 일본의 간행 사전(『日本史小辞典』, 『デジタル大辞泉』, 『世界大百科事典』 — 코토방크 게재)으로 작성자·연도를 확인했습니다.
4. **판정 기준**
   - `verified`(출처 확인): 원문 또는 소장·등재 기관의 공식 페이지를 직접 열어 자료명·작성 주체·연도·내용이 맞는 것을 확인
   - `partial`(일부 확인): 학술 사전·기관 기록으로 서지는 확인했지만, 원문 페이지나 일부 정보는 확인하지 못함
   - `unverified`(검토 전): 근거를 확인하지 못함
5. 확인하지 못한 것은 `verified`로 올리지 않았고, 무엇이 미확인인지 `verificationNote`에 적었습니다.
