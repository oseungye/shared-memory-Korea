# 참여율 높이기 — 학교 QR 포스터 운영 안내 (2026-10-24)

Shared Memory는 **역사 아카이브**이고 핵심 참여가 **주관식**이라, 지나가다 보고 바로 참여하기에는 문턱이 높습니다.
포스터는 그 문턱을 낮추는 첫 단계입니다. 이 문서는 포스터를 만들고 붙이고, 효과를 확인하는 방법을 정리합니다.

## 1. 문턱을 낮추는 원칙 — 포스터와 사이트가 같은 약속을 하도록

| 문턱 | 포스터에서 하는 약속 | 사이트에서 실제로 지키는 것 |
|---|---|---|
| “역사 공부 같다” | 큰 제목은 호기심 질문(“같은 전쟁, 세 개의 이름.”), 세 나라 이름과 `AI ?` | 첫 화면 없이 사건이 바로 열리고, 처음 보는 것은 세 나라의 이름·짧은 서술 |
| “글을 써야 한다” | “관점을 골라요 (3문항 · 정답 없음)”, “한 줄 소감 (건너뛰어도 돼요)” | 기본 체험은 객관식 3문항이 먼저, 소감은 비워도 카드가 만들어짐 |
| “오래 걸린다·가입해야 한다” | “3–5분 · 익명 · 로그인 없음 · 정답 없음” | 로그인·연령대 질문 없음 (휴대폰에서 첫 화면 → 카드까지 탭 8번 이하, 자동 테스트) |
| “나한테 남는 게 없다” | “나만의 Memory Card 완성 (이미지·인스타 스토리로 저장)” | 카드 4:5 / 스토리 9:16 PNG 저장 |
| “내 정보가 남는다” | “이름·연락처는 묻지 않아요 … 다른 사람에게 공개되지 않아요” | 소감에 연락처·이름·학교·학년/반이 있으면 저장 전에 막음 |

포스터 문구를 바꿀 때도 이 표의 오른쪽(실제 동작)과 어긋나지 않게 해 주세요. 예를 들어 “1분”처럼 측정하지 않은 시간은 쓰지 않습니다.

## 2. 포스터 만들기

1. 배포된 사이트에서 첫 화면 아래 **‘학교 포스터·수업용 QR 만들기’**를 엽니다.
   (QR에는 **지금 열려 있는 주소**가 들어갑니다. 로컬 주소에서 만들면 다른 휴대폰에서 열리지 않습니다.)
2. **QR을 찍으면 열릴 화면**을 고릅니다.
   - `임진왜란 바로 시작`(권장): 탭이 가장 적고, 포스터 제목과 첫 화면이 이어집니다.
   - `재일조선인 바로 시작`: 같은 학교에 두 종류를 함께 붙이면 어느 쪽이 더 참여를 끄는지 비교할 수 있습니다(4절).
   - `첫 화면`: 두 사건 중 고르게 할 때. 사건별 비교는 어렵습니다.
3. **포스터 맨 아래 문구**(선택, 60자): 동아리 이름·운영 기간·부스 위치 같은 운영 정보만. 개인 전화번호·SNS 계정은 넣지 않는 것을 권합니다(문구는 저장되지 않음).
4. **포스터 인쇄 · PDF로 저장 (A4)** → 인쇄 창에서 ‘배경 그래픽’ 켜기 권장. A3가 필요하면 PDF를 인쇄소에서 A3로 확대해도 QR·글자가 깨지지 않습니다(벡터).

## 3. 붙이기 — 체크리스트

- [ ] 학교(담당 선생님) 게시 허가 받기. 게시 기간을 포스터 맨 아래 문구에 적기
- [ ] **기다리는 곳**에 붙이기: 급식실 줄, 매점·엘리베이터 앞, 도서관 입구, 역사 교실 앞 (지나가는 복도보다 서 있는 곳)
- [ ] QR 높이는 바닥에서 약 120–150cm(눈높이). 반사가 심한 코팅·유리 뒤는 피하거나 무광 코팅
- [ ] 붙인 뒤 **휴대폰 2대 이상**(iPhone 기본 카메라, Android 기본 카메라, 카카오톡·네이버 앱 QR)으로 1–2m 거리에서 찍어 보기
- [ ] 붙인 날짜·장소·포스터 종류(임진왜란/재일조선인/첫 화면)를 기록 (4절 효과 확인용)
- [ ] 비·햇빛에 바랜 포스터는 교체 (QR이 흐려지면 읽히지 않음)

## 4. 효과 확인 — 지금 있는 기록만으로

참여 기록(`participation_pings`)은 사건 이름과 시각만 남기므로, **붙인 날짜 전후**와 **사건별**로 비교할 수 있습니다.
운영자가 Supabase SQL Editor에서 실행하는 조회입니다(읽기만 함).

```sql
-- 날짜별·사건별 참여 수 (한국 시간)
select (created_at at time zone 'Asia/Seoul')::date as day, event_key, count(*) as participants
from public.participation_pings
group by 1, 2
order by 1, 2;
```

- 임진왜란 포스터와 재일조선인 포스터를 같은 기간에 다른 곳에 붙이면, 사건별 수로 어느 포스터·장소가 효과적인지 대략 비교할 수 있습니다.
- 한계: 포스터로 들어왔는지, 수업·링크로 들어왔는지는 구분하지 않습니다(유입 경로를 저장하지 않음). 같은 학생이 다른 기기로 하면 두 번 셉니다.

## 5. 주관식(공동 표현) 참여를 늘리는 다음 단계 — 제안 (아직 구현하지 않음)

포스터는 **기본 체험(객관식 + 선택 소감)** 참여를 늘립니다. 공개 아카이브에 남는 주관식 ‘공동 표현’은 카드 화면의
“내 문장을 Shared Memory에 공개하기 (선택)”에서 이어지므로, 다음을 함께 쓰면 좋습니다.

| 방법 | 내용 | 비용·주의 |
|---|---|---|
| 역사 수업 5분 연계 | 수업 시작 5분에 포스터 QR로 기본 체험 → 끝에 ‘모두의 기억 보기’를 함께 보고 1–2명이 공개 표현 남기기 | 교사 협조 필요. 강제 참여·점수 반영은 하지 않기 |
| 복도 화면·부스 | 점심시간 부스에서 노트북으로 ‘모두의 기억 보기’를 띄워 두고 **↻ 최신 참여 불러오기**로 갱신 | 공개 동의한 문장만 보임. 부적절한 글은 `is_hidden`으로 즉시 숨김 |
| 카드 이미지에 사이트 주소 | 지금 저장되는 카드·스토리 이미지에는 사이트 주소가 없어, 인스타에 올려도 친구가 들어올 길이 없음 → 카드 아래에 짧은 주소(또는 작은 QR) 추가 | **기능 변경** — Feature Freeze(11/8) 전에 할지 결정 필요 |
| 유입 경로 기록 | QR 주소에 `?src=poster` 같은 표시를 붙이고 참여 기록에 함께 저장 → 포스터 효과를 정확히 측정 | **DB 변경**(참여 기록 칸 추가) — 승인 필요 |
| 경품·스탬프 | 하려면 카드 화면을 보여 주면 도장을 찍어 주는 **오프라인** 방식만 (이름·연락처를 받는 추첨은 익명 원칙과 충돌) | 학교 규정 확인 |
